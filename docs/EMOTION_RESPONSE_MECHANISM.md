# AI 居民如何根據當前情緒調整回應

## 核心機制說明

**回答您的問題：當 A 居民心情很糟時，他會依照當前的糟糕情緒來回應，而不是正常回應！**

系統確實像真人一樣，會根據當前情緒狀態調整對話內容。

---

## 完整情緒回應流程

### 1. 情緒狀態追蹤

每位 AI 居民都有一個 `EmotionState` 物件，持續追蹤：

```python
class EmotionState:
    emotion: str          # 當前情緒 (如 "sadness", "joy")
    intensity: float      # 情緒強度 (0.0 - 1.0)
    reasoning: str        # 情緒原因
    timestamp: datetime   # 時間戳記
    emotion_history: List # 情緒歷史記錄
```

**實際範例**：
```python
# 盧品蓉收到考試不及格通知後
{
    "emotion": "sadness",           # 當前情緒：悲傷
    "intensity": 0.75,              # 強度：很強烈（0.75/1.0）
    "reasoning": "收到數學考試不及格通知，擔心影響學期成績",
    "timestamp": "2025-11-22 14:00:00"
}
```

### 2. 開啟新對話時的情緒影響

當 A 居民遇到 B 居民開啟新對話時，系統會：

#### 步驟 1: 讀取當前情緒狀態
```python
# 在 agent.py 的 _chat_with() 方法中 (第 558-568 行)
if hasattr(self, 'generate_emotional_chat'):
    # 構建情境描述
    curr_context = f"{self.name} 正在 {self.get_event().get_describe()}，遇到了 {other.name}"

    # 使用情緒感知對話生成
    text = self.generate_emotional_chat(
        other_agent_name=other.name,
        chat_context=curr_context,
        chat_history=chats,
        use_mgt_rater=True  # 啟用 MGT 情緒評分員
    )
```

#### 步驟 2: MGT 評分員評估當前情境
```python
# 在 agent_emotion_mixin.py 的 generate_emotional_chat() 方法中 (第 266-280 行)
multimodal_input = MultimodalEmotionInput(
    text_content=chat_context,
    context_description=chat_context,
    retrieved_memories=memories_text,
    current_emotion=self.emotion_analyzer.current_emotion,  # ← 傳入當前情緒！
    target_agent_name=other_agent_name
)

# 調用 MGT 評分員
mgt_output = self.mgt_rater.rate_emotion(
    multimodal_input,
    agent_completion_func=self.completion
)
```

#### 步驟 3: 生成情緒驅動的提示詞
```python
# 在 mgt_prompts.py 的 prompt_mgt_enhanced_chat() 方法中 (第 56-80 行)
prompt = f"""你是 {agent_name}，正在與 {other_agent_name} 進行對話。

## 當前情緒狀態
{emotion_display}（強度：{current_emotion.intensity:.2f}）  # ← 當前情緒！
情緒原因：{current_emotion.reasoning}                      # ← 情緒原因！

## 對話風格
語氣：{tone}                                               # ← 情緒決定語氣
行為特徵：{emotion_style.get('behavior', '自然互動')}      # ← 情緒決定行為

## 對話情境
{chat_context}
{memory_context}
{mgt_guidance}

## 任務
請根據以上情緒狀態、對話情境和評分員建議，生成 {agent_name} 的回應。

要求：
1. 自然融入當前情緒（不要直接說出情緒名稱）  # ← 重要！
2. 考慮評分員的建議但保持自然
3. 符合 {agent_name} 的性格特質
4. 簡潔（2-3句話）
```

## 情緒持久性機制

### 情緒不會立即消失

當 A 居民經歷情緒觸發事件後，情緒會持續一段時間：

```python
# 情緒衰減機制
class EmotionState:
    def decay_over_time(self, time_elapsed_minutes: int):
        """情緒隨時間自然衰減"""
        decay_rate = 0.02 * time_elapsed_minutes  # 每分鐘衰減 2%

        # 情緒穩定性影響衰減速度
        emotional_stability = self.agent_config.get('emotional_stability', 0.6)
        adjusted_decay = decay_rate * (2 - emotional_stability)

        self.intensity = max(0.1, self.intensity - adjusted_decay)
```

**實際案例**：

```python
# 盧品蓉收到不及格通知
14:00 → sadness (強度 0.75)
14:30 → sadness (強度 0.68)  # 30分鐘後略微降低
15:00 → sadness (強度 0.61)  # 1小時後仍然悲傷
16:00 → sadness (強度 0.50)  # 2小時後逐漸平復
18:00 → neutral (強度 0.35)  # 4小時後基本恢復

# 在這 4 小時內的所有對話都會帶有悲傷情緒！
```

### 新事件可以改變情緒

但如果在情緒衰減期間發生新的強烈事件，情緒會改變：

```python
# 案例：悲傷中遇到好事
14:00 → sadness (0.75) - 考試不及格
15:00 → sadness (0.61) - 仍然悲傷
15:30 → 【新事件】好友主動安慰並陪伴學習
16:00 → joy (0.45) - 感受到友誼的溫暖，情緒轉為喜悅

# MGT 評分員會評估新情境並更新情緒
new_emotion = mgt_rater.appraise(
    text="好友真心安慰我並願意陪我一起學習",
    context="盧品蓉正處於悲傷中，好友莊于萱主動提供支持"
)
# 輸出: joy (0.45) - 因為支持帶來正面情緒
```

## 技術實現細節

### 情緒如何傳遞到 LLM

整個流程的關鍵在於 **提示詞工程 (Prompt Engineering)**：

```python
# 完整的提示詞結構
final_prompt_to_llm = f"""
{system_role}          # 角色定義（如：你是盧品蓉）

{current_emotion}      # ← 關鍵！當前情緒狀態
強度: {intensity}      # ← 關鍵！情緒強度
原因: {reasoning}      # ← 關鍵！為什麼有這個情緒

{emotion_style}        # 情緒對應的語氣和行為
語氣: {tone}
行為: {behavior}

{mgt_suggestions}      # MGT 評分員的具體建議
1. [建議 1]
2. [建議 2]
3. [建議 3]

{context}              # 當前情境
{memory}               # 相關記憶

{task}                 # 任務要求：根據以上情緒生成回應
"""

# LLM 接收到這個提示詞後，會自然地考慮情緒來生成回應
```

### 為什麼 LLM 能理解情緒並正確回應？

1. **明確的情緒指示**：提示詞中直接說明當前情緒和強度
2. **情緒風格指導**：提供語氣、行為特徵的具體描述
3. **MGT 建議**：給出更細緻的互動建議
4. **要求自然融入**：指示 LLM 不要直接說出情緒名稱，而是透過語氣和內容表現

**範例提示詞片段**：
```
你是盧品蓉，正在與魏祺紘對話。

當前情緒：😢 悲傷（強度 0.75）
原因：剛收到數學考試不及格通知

語氣：低沉
行為：沉默、迴避眼神接觸

MGT 建議：
1. 語氣應該帶有些許無力感
2. 回應較簡短
3. 如果關心可能會流露傾訴意願

要求：自然融入當前情緒（不要直接說"我很悲傷"）
```

→ LLM 理解後生成：
```
"嗨...祺紘。我今天考試考得不太好，現在不太想去咖啡館...對不起。"
```
而不是：
```
"嗨，祺紘！我現在很悲傷，因為考試不及格。" ← 不自然
```

## 真實性驗證案例

### 測試場景：連續對話中的情緒一致性

```python
# 測試：盧品蓉在悲傷狀態下的連續互動

【時間 14:15】互動 1：在走廊遇到鄭傑丞
鄭傑丞: "品蓉，妳還好嗎？看起來心情不太好。"
盧品蓉: "其實不太好...我數學考試沒過。我真的不知道該怎麼跟家人說。"
        ↑
   情緒一致：悲傷、失落

【時間 14:30】互動 2：在圖書館遇到魏祺紘

        ↑
   情緒一致：仍然悲傷、想要獨處
```

### 回答您的核心問題

**問**: 當今天 A 人心情不好（當前心情是很糟），在開啟新對話時，他是會依照很糟的當前心情去回覆，還是正常的回覆？

**答**: **他會完全依照當前的糟糕心情去回覆！**

系統的設計目標就是讓 AI 居民像真人一樣：

1. ✅ **持續追蹤情緒狀態**：每個事件都會更新情緒
2. ✅ **情緒影響所有互動**：無論是主動還是被動對話
3. ✅ **自然表達情緒**：透過語氣、內容、行為特徵
4. ✅ **情緒有持久性**：不會瞬間消失，會自然衰減
5. ✅ **個性化反應**：不同居民對同一事件有不同情緒反應
6. ✅ **情緒可以改變**：新的事件可以更新情緒狀態

### 技術保證

系統透過以下機制確保情緒真實影響對話：

1. **情緒狀態持久化**：`EmotionState` 物件持續追蹤
2. **MGT 即時評估**：每次對話前評估當前情緒和情境
3. **提示詞工程**：將情緒明確注入 LLM 提示詞
4. **情緒風格映射**：不同情緒對應不同語氣和行為
5. **情緒衰減機制**：情緒隨時間自然變化
6. **記憶系統整合**：情緒歷史影響未來行為

這個系統之所以真實，是因為：

- **不是隨機**：基於情境和歷史的理性評估
- **不是即時**：情緒有持久性和衰減過程
- **不是單一**：考慮多種因素（情境、記憶、個性、關係）
