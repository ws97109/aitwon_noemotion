## 情緒改變機制

### 🔄 情緒更新流程

**位置**: [emotion_system/core.py:235-255](emotion_system/core.py#L235-L255)

```python
def update_emotion(self, new_emotion: EmotionState):
    """
    更新當前情緒狀態

    考慮情緒穩定性，平滑過渡
    """
    # 1. 記錄歷史
    if self.current_emotion.emotion != "neutral":
        self.emotion_history.append(self.current_emotion)

    # 2. 根據情緒穩定性調整強度
    stability_factor = self.config.emotional_stability  # 來自配置
    adjusted_intensity = new_emotion.intensity * (1 - stability_factor * 0.3)

    # 3. 更新情緒狀態
    self.current_emotion = EmotionState(
        emotion=new_emotion.emotion,
        intensity=max(0.1, min(1.0, adjusted_intensity)),  # 限制在 0.1-1.0
        reasoning=new_emotion.reasoning,
        timestamp=datetime.now().isoformat(),
        duration=new_emotion.duration
    )
```

### 📊 情緒穩定性影響

每個 Agent 在配置中有 `emotional_stability` 參數：

```json
{
  "emotion_config": {
    "emotional_stability": 0.8,  // 0.0-1.0，越高越穩定
    "empathy_level": 0.9,
    "optimism": 0.7,
    "anxiety_proneness": 0.3
  }
}
```

**影響公式**：
```python
adjusted_intensity = new_intensity * (1 - stability * 0.3)

例子：
- 新情緒強度 = 0.8
- stability = 0.8（高穩定）
- 調整後 = 0.8 * (1 - 0.8 * 0.3) = 0.8 * 0.76 = 0.608

- stability = 0.2（低穩定）
- 調整後 = 0.8 * (1 - 0.2 * 0.3) = 0.8 * 0.94 = 0.752
```

**意義**：
- 😌 **高穩定性** (0.8-1.0)：情緒變化較平滑，不易激動（如：游庭瑄 0.8）
- 😃 **低穩定性** (0.0-0.3)：情緒變化劇烈，容易被影響（如：魏祺紘 0.6）

### 🕐 情緒衰減機制

```python
def check_emotion_decay(self, current_time: datetime) -> bool:
    """檢查情緒是否需要衰減"""
    emotion_time = datetime.fromisoformat(self.current_emotion.timestamp)
    minutes_passed = (current_time - emotion_time).total_seconds() / 60

    if minutes_passed > 5:  # 每5分鐘檢查一次
        old_emotion = self.current_emotion.emotion
        self.current_emotion = self.current_emotion.decay(int(minutes_passed))
        return old_emotion != self.current_emotion.emotion

    return False
```

**衰減規則**：
```python
# EmotionState.decay() 方法
def decay(self, minutes_passed: int) -> EmotionState:
    # 每5分鐘衰減一次
    decay_cycles = minutes_passed // 5

    # 強度衰減公式
    new_intensity = self.intensity * (0.9 ** decay_cycles)

    # 如果強度降到 0.2 以下，回歸中性
    if new_intensity < 0.2:
        return EmotionState(
            emotion="neutral",
            intensity=0.3,
            reasoning="情緒已自然衰減",
            timestamp=datetime.now().isoformat()
        )

    return EmotionState(
        emotion=self.emotion,
        intensity=new_intensity,
        reasoning=self.reasoning,
        timestamp=self.timestamp,
        duration=self.duration
    )
```

```
25分鐘       0.59 (衰減 41%)
```

**平行多模態流模組**：
```python
class ParallelMultimodalFlow:
    def project_modalities(self, text, context, memory):
        # 1. 文字投影（保留語言特徵）
        text_proj = np.tanh(np.dot(text, self.W_text) + self.b_text)

        # 2. 多模態投影（融合情境和記憶）
        multimodal = np.concatenate([context, memory])
        multimodal_proj = np.tanh(
            np.dot(multimodal, self.W_multimodal) + self.b_multimodal
        )

        return text_proj, multimodal_proj
```

#### 步驟 3: 跨模態注意力

```python
# 計算注意力權重
multimodal_fused, attention_weights = self.attention.compute_attention(
    text_proj,        # Query（文字）
    multimodal_proj,  # Key & Value（情境+記憶）
)
```

**跨模態注意力機制**：
```python
class CrossModalAttention:
    def compute_attention(self, query, key_value):
        # 1. 計算注意力分數
        scores = []
        for kv in key_value_list:
            score = np.dot(query, kv) / np.sqrt(self.hidden_dim)
            scores.append(score)

        # 2. Softmax 歸一化
        attention_weights = self._softmax(scores)

        # 3. 加權融合
        fused = sum(w * kv for w, kv in zip(attention_weights, key_value_list))

        return fused, attention_weights
```

**注意力權重意義**：
- `attention_weights[0]`：情境的重要性
- `attention_weights[1]`：記憶的重要性

#### 步驟 4: 閘控機制


**閘控機制**：
```python
class GatingMechanism:
    def compute_gate(self, text_rep, multimodal_rep):
        # 1. 計算閘控值（0-1）
        concat = np.concatenate([text_rep, multimodal_rep])
        gate = self._sigmoid(np.dot(concat, self.W_gate) + self.b_gate)

        # 2. 動態融合
        # gate 接近 1：更多使用多模態資訊
        # gate 接近 0：更多保留語言特徵
        final = gate * multimodal_rep + (1 - gate) * text_rep

        return final, gate
```

**閘控值意義**：
```
gate = 0.8：80% 多模態 + 20% 語言
gate = 0.3：30% 多模態 + 70% 語言
```

#### 步驟 5: 情緒分類

```python
# 計算各情緒的分數
emotion_scores = {}

if self.is_trained:  # 使用訓練好的分類器
    for emotion, weights in self.emotion_classifier.items():
        # 兩層神經網絡
        # Layer 1: 768 -> 384 with ReLU
        hidden = np.dot(final_rep, weights['layer1_W'].T) + weights['layer1_b']
        hidden = np.maximum(0, hidden)  # ReLU

        # Layer 2: 384 -> 1
        score = np.dot(hidden, weights['layer2_w']) + weights['layer2_b']
        emotion_scores[emotion] = score
else:  # 使用簡化分類器
```

#### 步驟 6: 計算情緒強度

```python
def _compute_intensity(self,
                      emotion_probs: Dict[str, float],
                      current_emotion: Optional[EmotionState]) -> float:
    max_prob = max(emotion_probs.values())
    base_intensity = max_prob

    # 考慮情緒轉換的平滑性
    if current_emotion:
        predicted = max(emotion_probs, key=emotion_probs.get)
        if predicted == current_emotion.emotion:
            # 同一情緒，強度變化較平滑
            base_intensity = 0.7 * base_intensity + 0.3 * current_emotion.intensity
        else:
            # 情緒轉換，強度較激烈
            base_intensity = min(base_intensity * 1.2, 1.0)

    return min(max(base_intensity, 0.0), 1.0)
```

**強度計算邏輯**：
```
情況1：情緒保持（joy → joy）
  新強度 = 0.7 * 預測機率 + 0.3 * 舊強度
  效果：平滑過渡

情況2：情緒轉換（joy → sadness）
  新強度 = 預測機率 * 1.2 (最高1.0)
  效果：較激烈的變化
```

```python
def apply_emotion_bias_to_retrieval(
    self,
    candidates: List[Any],
    top_k: int
) -> List[Tuple[Any, float]]:
    """情緒偏差應用於記憶檢索"""

    # 獲取當前情緒偏差
    emotion_bias = self.emotion_analyzer.get_emotion_bias_for_retrieval()

    for node, base_score in candidates:
        multiplier = 1.0

        # 1. 情緒偏向加成
        node_emotion = emotional_concept.initial_emotion
        if node_emotion and node_emotion in emotion_bias:
            multiplier *= emotion_bias[node_emotion]  # 1.5x

        # 2. 情緒強度影響
        intensity_factor = emotional_concept.emotion_intensity
        multiplier *= (0.8 + 0.4 * intensity_factor)

        # 3. 重要性加成
        if emotional_concept.poignancy >= 8:
            multiplier *= 1.1

        adjusted_score = base_score * multiplier
```

## 總結

### ✅ 情緒判斷機制

1. **觸發條件**：
   - 事件重要性 >= 5
   - 對話互動時

2. **判斷方法**：
   - LLM 評估（考慮性格、歷史、重要性）
   - MGT 多模態評估（對話時）
   - 規則評估（快速模式）

3. **考慮因素**：
   - 事件描述
   - 角色性格
   - 情緒歷史
   - 對話情境
   - 相關記憶
   - 對方資訊

### ✅ 情緒改變機制

1. **更新邏輯**：
   - 記錄歷史
   - 根據穩定性調整強度
   - 平滑過渡

2. **衰減機制**：
   - 每5分鐘衰減10%
   - 約40分鐘回歸中性
   - 可被新事件打斷

3. **影響範圍**：
   - 對話風格（語氣、行為）
   - 記憶檢索（情緒偏向）
   - 狀態描述（帶情緒色彩）
   - 互動建議（MGT）
